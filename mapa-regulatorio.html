Quantidade de registros regulatórios vinculados a cada tema do acervo.

Como interpretar

Uma concentração maior de registros pode indicar atenção regulatória mais intensa, maior complexidade institucional ou mais pontos de impacto naquele tema. A quantidade, isoladamente, não determina sua importância: ela oferece uma perspectiva comparativa para orientar a leitura do acervo.

Clique uma vez em um tema para abrir ou recolher suas normas diretas. Arraste para posicioná-lo livremente. Clique duas vezes para mostrar ou recolher conexões compartilhadas. Repouse o cursor para destacar conexões temporariamente. Use o botão Reorganizar para retornar à visualização inicial.
